AI 소싱팀 v11 — AI 직원 감사 시스템

목적:
AI 직원들이 낸 결과를 그대로 믿지 않고 총괄팀장 결재 전에 다시 검증합니다.

자동 감사 항목:
1. 상품명·매입가 근거
2. 국내 판매가 비교 — 링크 개수 + 웹 교차검증
3. 인증·규제 — 한국 공식기관 근거 우선 검색
4. 국제운송·통관 — 실제 견적이 아닌 경우 반드시 '추정값'
5. 원가·마진 계산식 — 브라우저에서 독립 재계산

표시:
✅ 확인됨
🟡 추정값
⚠ 재확인 필요
🔴 결재 보류

신뢰도 점수와 총괄 결재 상태를 표시합니다.
어린이/식품/전기전자처럼 규제 위험이 큰 카테고리는 공식 근거가 없으면 총괄 결재를 보류합니다.

중요:
이 감사 시스템도 자동화 도구이며 법률/인증의 최종 판단자는 아닙니다.
KC, 전파, 식품, 의료, 관세 등은 실제 수입 전 공식기관/관세사/시험기관 확인이 필요합니다.
