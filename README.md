# AI 소싱팀 v7.2 — 금액/상세페이지 오류 수정

## 핵심 수정
1. 새 상품 링크를 읽을 때 이전 상품의 매입가·판매가·운송비·통관비를 0으로 초기화합니다.
2. 상품 가격 자동감지에 실패하면 이전 숫자로 계산하지 않습니다.
3. 매입가가 없으면 분석 시작 자체를 막고 직접 입력하도록 안내합니다.
4. 국내 자동비교가 성공하면 그 평균가를 예상 판매가에 반영한 뒤 수익성을 다시 계산합니다.
5. 국내 가격도 못 찾으면 판매가 입력 전 수익성/최종판정을 보류합니다.
6. Temu 같은 사이트명만 상품명으로 읽히는 경우를 제거했습니다.
7. 상세페이지는 고객용으로 다시 만들었습니다.
   - 사입원가 / 순이익 / 마진율 노출 제거
   - 상품 이미지가 읽히면 상세 첫 화면에 표시
   - 핵심 장점 3개
   - 추천 대상
   - 구매 전 확인사항
   - 상품 기본 정보
8. 상세페이지 HTML 저장 기능은 그대로 유지합니다.

## 중요한 한계
Temu/Alibaba/AliExpress는 외부 자동읽기를 차단할 수 있습니다.
그 경우 상품명·매입가를 직접 입력해야 합니다.
이제는 자동읽기 실패 시 임의의 이전값으로 결과를 내지 않습니다.
