# AI 소싱팀 v7

## 추가된 AI 직원
### 7. 자동비교 직원
상품명을 기준으로 국내 검색 결과를 읽어 네이버/쿠팡 관련 가격 후보를 자동 수집합니다.
- 감지 최저가
- 감지 평균가
- 내 예상 판매가의 시장 포지션
- 검색 결과 가격 목록

검색엔진/쇼핑몰의 차단이나 페이지 구조에 따라 가격을 충분히 못 읽을 수 있습니다.
최종 판매 전에는 실제 네이버쇼핑/쿠팡에서 다시 확인하세요.

### 8. 디자인 직원
상품 카테고리, 위험도, 판매가, 마진, 국내 가격비교 결과를 이용해 상세페이지 초안을 자동 생성합니다.
- 첫 화면 헤드라인
- 핵심 장점 3개
- 추천 대상
- 구매 전 주의사항
- 가격/마진/인증 정보
- CTA 문구

상세페이지는:
- 문구 복사
- HTML 파일 저장
이 가능합니다.

### 9. 총괄팀장
모든 결과를 모아 최종 사입 판단을 냅니다.

## 실행
Windows: START_AI_SOURCING.bat
또는 index.html 직접 실행
