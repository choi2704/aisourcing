# AI 소싱팀 v3

이번 버전은 '누구나 쉽게 쓰는 AI 직원 프로그램' 컨셉으로 만든 실제 동작형 시제품입니다.

## 포함 기능
- 상품명 / 상품 링크 입력
- 7명 AI 직원 순차 분석 애니메이션
- 각 직원 진행률: 대기중 → 작업중 → 완료
- 실시간 작업기록
- 매입가 / 수량 / 국제운송 / 통관 / 플랫폼수수료 / 국내배송 / 포장 / 광고 / 반품충당 계산
- 경쟁강도 / 인증위험 반영
- 사입점수 100점
- 최종 판정
  - 🟢 샘플 구매 추천
  - 🟡 소량 테스트
  - 🔴 사입 비추천
  - 🔴 사입 보류
- 최근 분석 상품 저장 / 검색 / 삭제
- PC / 모바일 반응형

## 중요
현재 v3는 실제 쇼핑몰 페이지 자동수집 또는 외부 AI API 연결 전 단계입니다.
상품 URL은 저장용이며 자동 크롤링하지 않습니다.
API 키를 프론트엔드 코드에 직접 넣으면 노출될 수 있으므로 실제 AI 연동은 서버/서버리스 방식이 필요합니다.
